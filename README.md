# .github

Organization profile and default community files for [Lumanic AI](https://github.com/lumanic-ai).

| Path | Purpose |
|---|---|
| `profile/README.md` | The page shown at github.com/lumanic-ai |
| `profile/assets/` | Its figures, in light and dark variants |
| `brand/` | Mark, lockups and avatar |
| `tools/profile-figures/` | Source that regenerates the figures and brand files; `.github/workflows/profile-figures.yml` rebuilds them on every change |
| `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md` | Defaults for every repository that does not define its own |
| `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md` | Default issue forms and pull request template |
